AFTERBI WEBSITE PICTURES
========================

Every picture on the public site is a file in this folder (public/site/). Nothing is uploaded in Platform.
Name each file EXACTLY as on the left, as .webp, .png or .jpg (e.g. hero.jpg). Keep each under 300 KB.
Until a file is here, the page draws its own picture.

Customer logos go in public/site/logos/ and are listed in LOGOS in src/lib/site.ts.
